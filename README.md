# AlphaFlow 朋友試用版

台股主動 ETF 持股增減、個股查詢與回測研究。以正式站 v62 為基準；不是即時交易系統，也不執行交易。

正式站：https://alphaflow-observation-lab.wl03005685.chatgpt.site/

此庫僅含已公開的前端與基金資料，不含採集私鑰、登入資訊或個人證據庫。私人完整備份獨立保存。

## 手機使用

iPhone：Safari 開啟試用站 → 分享 → 加入主畫面。
Android：Chrome 開啟試用站 → 選單 → 安裝應用程式／新增至主畫面。
這是 PWA 網頁 App，未上架 App Store 或 Google Play。需要網路讀取資料；不快取行情或持股。

## 資料更新

GitHub Actions 每小時第 10 分鐘，以及台灣時間每日 07:50、08:50、21:50、23:50 嘗試從正式站同步全部公開持股與異動資料。排程可能延遲，並不保證 08:00 前完成。同步成功不代表每檔 ETF 官方資料均已更新；請查看各檔日期與失敗狀態。
核對來源內容版本與逐檔 SHA-256 後才發布；若同步失敗，保留上一版，頁面顯示上一版同步時間。

## 維護

`npm test` 驗證路徑、安裝資訊與私人 API 隔離。
`npm run sync` 同步公開資料。設定 GitHub Pages 的發布來源為 GitHub Actions。
證據庫與筆記須在正式站登入使用，試用站不儲存個人資料。
